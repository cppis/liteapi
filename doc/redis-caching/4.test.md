## HTTP 통합 테스트 (`Test.http/test-cache.http`)

Redis와 MySQL이 실행 중일 때 수동으로 실행하는 시나리오:

| # | 요청 | 검증 |
|---|------|------|
| 1 | POST /api/users | 유저 생성 |
| 2 | GET /api/users/1 | 캐시 미스 → DB 조회 → 캐시 저장 (로그 확인) |
| 3 | GET /api/users/1 | 캐시 히트 → DB 쿼리 없음 (로그 확인) |
| 4 | PUT /api/users/1 | Load → Process → Save → 캐시 무효화 |
| 5 | GET /api/users/1 | 캐시 미스 → 최신 데이터 반환 |
| 6 | POST /api/users/1/add-gold | Load → Process → Save → 캐시 무효화 |
| 7 | GET /api/users/1 | 캐시 미스 → 골드 증가 반영 확인 |
| 8 | GET /api/users | 목록 캐시 (TTL 30초) |
| 9 | GET /health | Redis 상태 Healthy/Degraded 확인 |
| 10 | GET /metrics | cache_hits/misses/duration 카운터 확인 |
